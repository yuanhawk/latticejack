What this does

Clicking Start boots a real Azure VM, runs this project's demo scripts on it over a real network, and streams the raw output back here. It is not instant - expect roughly 4 to 7 minutes end to end (VM boot, then four stages: a classical-TLS baseline, the hybrid-PQC upgrade, a native ML-KEM provider variant, and a real local LLM request fronted by the same hybrid handshake).

Only one live run at a time. If someone else's run is in progress you'll land in spectator mode on their session instead of starting a new one.
